# Dev Crew — портативная «агентная фабрика»

Разворачиваемая одной командой команда разработки ПО из изолированных агентов (Docker-контейнеры). Каждый инженерный агент работает в своём окружении, со своими инструментами и навыками.

## Состав

### Инфраструктурные контейнеры

| Контейнер | Назначение |
|-----------|------------|
| `shared-memory` | Общая память команды (контекст, артефакты, история) |
| `dev-cluster` | Среда разработки |
| `staging-cluster` | Стейджинг-среда |
| `preprod-cluster` | Предпродакшн-среда |

### Инженерные агенты

| Агент | Роль |
|-------|------|
| `developer` | Пишет код, работает с git, создаёт PR |
| `qa` | Тестирует, проверяет, контролирует качество |
| `tech-pm` | Декомпозиция задач, приоритизация, координация |

## Токены

Единый файл-источник правды: `tokens/tokens.yaml` (реальные значения, gitignored) + шаблон `tokens/tokens.example.yaml`. Монтируются в контейнеры read-only.

- **GitHub** — push/pull, PR, review
- **LLM API** — OpenAI-совместимый контракт (`OPENAI_BASE_URL` + `OPENAI_API_KEY` + модель)

## Общий регистр действий

Шина обмена между агентами. Схема сообщения — `bus/action-schema.json`.

## Статус

Проект в активной проработке. См. `docs/architecture.md` и Linear-эпик.
